# Source and License Boundary

iLS Gateway is an original Go/OpenWrt implementation based on publicly
observable protocol behavior. This repository does not bundle source files,
assets, or code from other location-spoofing projects. Original project code is
MIT licensed; third-party dependencies retain their respective licenses.

The OpenWrt package is intended only for authorized devices on a LAN owned or
administered by the operator.
